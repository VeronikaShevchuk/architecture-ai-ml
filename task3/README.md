# Векторный индекс базы знаний

## Описание
Этот проект создает векторный индекс для базы знаний на основе фантастического переложения романа "Мастер и Маргарита" - "Хроники Сумеречного Легиона".

## Использованная модель эмбеддингов

**Название модели:** `all-MiniLM-L6-v2`
**Источник:** HuggingFace / sentence-transformers
**Ссылка:** https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2
**Размер эмбеддингов:** 384
**Описание:** Легкая и быстрая модель для создания эмбеддингов текста. Хорошо подходит для поиска релевантных фрагментов.

### Альтернативные модели:
- `intfloat/multilingual-e5-small` - мультиязычная модель (384)
- `BAAI/bge-small-en-v1.5` - английская модель (384)
- `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` - мультиязычная (384)

## База знаний
- Исходная папка: `./original_texts` (оригинальные тексты)
- Обработанная папка: `./knowledge_base` (тексты с заменой терминов)
- Форматы файлов: `.txt`, `.md`

## Характеристики индекса

| Параметр | Значение |
|----------|----------|
| Модель эмбеддингов | all-MiniLM-L6-v2 |
| Размер эмбеддинга | 384 |
| Размер чанка | 500 символов |
| Перекрытие чанков | 50 символов |
| Количество документов | зависит от базы |
| Количество чанков | зависит от базы |
| Тип индекса | FAISS |
| Время индексации | ~2-5 минут (зависит от объема) |

## Использование

### Создание индекса

##### ПОЛНАЯ ПОСЛЕДОВАТЕЛЬНОСТЬ ЗАПУСКА

##### 1. Активация окружения
    .venv\Scripts\activate

##### 2. Установка зависимостей
    pip install -i https://mirror.yandex.ru/pypi/simple sentence-transformers
    pip install langchain langchain-community faiss-cpu numpy tqdm

##### 3. Проверка файлов
    dir original_texts
    dir knowledge_base

##### 4. Если dir knowledge_base пустая, то создать 
    python prepare_knowledge_new.py

##### 5. Запуск создания индекса
    python build_index_correct.py

##### 6. Тестирование поиска
    python search_index.py "Неуклюжая"
