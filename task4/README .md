# RAG-бот с техниками Few-shot и Chain-of-Thought

## Описание
RAG-бот для фантастического мира "Хроники Сумеречного Легиона" с применением современных техник промптинга.

## Техники промптинга

### 1. Few-shot prompting
В промпт добавляются 1-2 примера вопросов и ответов из той же предметной области:
- "Кто такой Архивариус?" → пример ответа
- "Что случилось на Парке Встреч?" → пример ответа

### 2. Chain-of-Thought (CoT)
Бот явно показывает свою цепочку рассуждений:
1. Анализ запроса
2. Поиск в контексте
3. Проверка наличия информации
4. Формирование ответа

### 3. Обработка отсутствия информации
Если информация не найдена, бот отвечает "Я не знаю"
